# Numbersense
I want UIL number sense practice to be accessible, convenient, fun and free.
A reason why I made this is because there aren't many resources for people who want to practice number sense,
and more specifically UIL number sense (because it is pretty specific), eventually, I got tired of using
the same zetamac settings, trying to configure it to be something that it just isn't.Because of this , I thought
that it was my responsibility to use my sub-par coding skills to make something acutally useful.
